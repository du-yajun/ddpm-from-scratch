# Day 1 笔记（9/7 任务，9/8 补做）

## 问答

1. **ToTensor 之后范围和形状是什么？**
   像素从 uint8 [0,255] 变成 float32 [0,1]，形状 (1, 28, 28)，即 (C,H,W)。

2. **Normalize(0.5, 0.5) 做了什么？**
   对每个像素值做 (v−0.5)/0.5 = 2v−1，把 [0,1] 线性映射到 [-1,1]。归一化的是数值，不是"通道维"。

3. **为什么必须归一化到 [-1,1] 而不是 [0,1]？**
   生成时从纯噪声 x_T ~ N(0, I) 出发，噪声以 0 为中心、正负都有；图像归到 [-1,1] 后，信号域和噪声域处在同一个数值世界。

4. **为什么单张图打印出 max=0.9922？**
   那张图最亮的像素是 254 而不是 255。验收要看全量 60000 张的全局 min/max，单张图不代表数据集。

5. **为什么比较时要用 .item()？**
   `x.max()` 返回 tensor 标量，`.item()` 转成 Python float，避免和 `float("-inf")` 混用导致类型混乱。

## 重点

MNIST 像素用 2v−1 归一化到 [-1,1]；全量验收 `x.min()=-1, x.max()=1`。目的：让图像信号和纯噪声 N(0,I) 处在同一个数值世界。
