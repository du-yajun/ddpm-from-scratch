# Day 3 笔记（2026-09-09）

## 问答

1. **为什么不能直接把 t 的数值喂给网络？**
   单个数字信息量小、没有结构；embedding 把 t 展开成高维向量，给网络一个容易和图像特征融合的表示。

2. **i=0 和 i 大时哪个更敏感？频率怎么变化？为什么？**
   i=0 最敏感（高频）；频率随 i 增大变低。高频管细节（区分相近 t），低频管稳定（全局信息），混合起来向量既独特又稳定。

3. **为什么相近的 t 得到的向量也相近？**
   sin/cos 连续，t 小幅变化时输出近似不变，所以 embedding 随 t 平滑过渡。

4. **返回形状是什么？dim 为什么必须是偶数？**
   (B, dim)。sin/cos 成对出现、各占一个位置，i 从 0 数到 dim/2−1，奇数会错位。

5. **写代码时踩了什么坑？**
   指数 (2i/dim) 是 0~1 的小数，转成 int64 会全变 0，导致所有频率等于 1、embedding 退化；底数应是 10000 而不是 100000。

6. **两两余弦相似度矩阵怎么算？**
   先把每行归一化成长度 1，再乘自己的转置：`sim = norm @ norm.T`，对角线为 1。

## 重点

时间步编码公式：`emb[2i]=sin(t/10000^(2i/d))`、`emb[2i+1]=cos(t/10000^(2i/d))`；高频区分相近 t、低频提供稳定信息——这是把"噪声强度"作为条件喂给 U-Net 的基础。
